# SmartLabel数据管理层接口规范（面向开发者）

## 一、创建任务界面基本流程

1. 用户登录系统，点击“创建任务”按钮，进入创建任务界面。
    - 填写任务名称，任务描述，选择目标任务（图像分类、文本分类）。**注意：根据不同的标注模式呈现不同的界面**
       - 若目标任务是：图像分类，则开放两个文件上传框：数据集上传框（必填，格式为.zip压缩文件，且内容必须是图片格式）和标注文件上传框（选填，格式为.csv/.txt/.json格式） 。
         - 规定：用户提供的图像标注文件的格式（每条）为：
           - .csv文件：`"图像的文件名称","标签"`
           - .txt文件：`图像的文件名称,标签`
           - .json文件：`{"filename":"图像的文件名称","label":"标签"}`
       - 若目标任务是：文本分类，则开放一个文件上传框：数据集上传框（必填，格式为.csv/.txt/.json格式） 。
         - .txt文本格式规范：`"text",label`（文本信息用最外层`""`标识，以逗号分隔数据和标签）
           - 如：`"股票市场波动很大",金融`
         - .json文本格式规范：`{"text": "...", "label": "..."}` 
           - 如：`{"text": "股票市场波动很大", "label": "金融"}`
         - .csv文本格式规范：`"text","label"`
           - 如：`"股票市场波动很大","金融"`

2. 点击“创建任务”按钮，平台对用户输入表单信息进行校验：
    - 具体校验步骤如下：
      - a. 必填内容是否填写；
      - b. 上传文件是否符合规定的文件要求（如数据集上传框上传的文件格式是否正确）；
      - c. 标注文件内容是否规范；
      - d. 标注文件内容中是否出现上传数据中没有的文件名 。
    - 当上述校验步骤任意一项没有通过，提示对应的报错信息；当所有步骤都通过时，判断用户上传任务是预训练模式还是半监督模式，并弹出任务配置框。
    - **说明：在图像分类任务下，根据是否上传标注文件判断预训练/半监督情形；在文本分类任务下，根据文件中有无"label"判断预训练/半监督情形**

3. 任务配置框的主要内容：
    - 信息1：选取模型尺寸大小；
    - 信息2：所有类别标签；（如果是预训练情况则需要用户手动输入全部标签，如果是半监督情况则由平台自动获取用户提供的标注文件/已标注文件中的全部标签） 。

4. 用户确认任务配置框中的内容无误，在选取模型尺寸大小后，可以点击“开始标注”，在后台创建任务，并跳转到标注界面 。

## 二、管理任务界面基本流程

1. 用户登录系统，点击“管理任务”按钮，或者在创建任务完成后，进入管理任务界面 。
2. 在管理界面中可以按照“任务状态”、“目标任务类别”和“任务名称”进行查找、筛选任务 。
3. 对于各个任务，显示其当前进度（预训练模式下显示测试进度条，而半监督模式下分两段进度条（训练进度条和测试进度条）） 。
4. 对于各个任务，有“查看详情”和“删除”两个按钮，点击“查看详情”按钮后进入具体任务详情页面；而点击“删除”按钮后提示是否将该任务删除 。
    - **注意：在点击“查看详情”后，需要根据该任务的类别，显示不同的查看界面效果！**

---

## 三、项目详情查看界面基本流程

1. 用户点击管理任务界面中需要查看的任务的“查看详情”按钮，进入项目详情查看界面 。
2. 用户可以点击项目内容的缩略图（图像任务显示缩略图，文本任务显示部分字符），查看完整内容 。
3. 用户可以对所有标注内容按照置信度、类别或者有无标注进行筛选/排序 。
4. 用户可以对标注结果进行校验，使用下拉搜索框修改标注结果 。
