# SmartLabel算法层接口规范（面向开发者）

## 一、图像分类算法规范
图像数据主要的输入格式是.jpg、.jpeg或者.png，用户主要通过压缩包的方式上传数据集。

### 1. 预训练模式
预训练模式下，只需要使用已有的预训练模型对图片进行分类即可。

**test.py（测试函数）：**  
函数输入：单张图片数据  
函数输出：预测置信度 预测标签

### 2. 半监督模式
半监督模式下，需要提供含有标签的图片数据及未标注图片数据训练模型，在模型训练完成后，依次对未标注图片进行分类，输出结果。

**train.py（训练函数）：**  
函数输入：标注数据集 未标注数据集  
函数输出：训练完成模型的路径位置

**test.py（测试函数）：**  
函数输入：单张图片数据  
函数输出：预测置信度 预测标签

## 二、文本分类算法规范
文本数据主要的输入格式是.txt、.csv或者.json格式，用户在上传文件时直接将相应文件传入即可。

.txt文本格式规范：`"text", label`（文本信息用最外层`""`标识，以逗号分隔数据和标签）  
如：`"股票市场波动很大", 金融`  

.json文本格式规范：`{"text": "...", "label": "..."}`  
如：`{"text": "股票市场波动很大", "label": "金融"}`  

.csv文本格式规范：`"text", "label"`  
如：`"股票市场波动很大", "金融"`

### 1. 预训练模式

**test.py（测试函数）：**  
函数输入：文本数据格式（.txt/.json/.csv） 单条文本数据  
函数输出：预测置信度 预测标签

### 2. 半监督模式

**train.py（训练函数）：**  
函数输入：文本数据格式（.txt/.json/.csv） 文本数据文件  
函数输出：训练完成模型的路径位置

**test.py（测试函数）：**  
函数输入：文本数据格式（.txt/.json/.csv） 单条文本数据  
函数输出：预测置信度 预测标签
